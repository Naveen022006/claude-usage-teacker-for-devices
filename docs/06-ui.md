# 06 — UI

## Widget (primary UI, injected on claude.ai)

### Sidebar panel (default placement)
`src/widget/anchor.ts` finds the left sidebar and inserts the panel as a sibling right after one row
(never inside React-owned nodes; if React removes it, it is re-inserted):
- **Chat** (any path not starting with `/code`): directly below the **Customize** row (`a[href*="/customize"]`, else a row whose
  text is "Customize", else a language-tolerant fallback: the last nav row before the first section heading), above "Pinned".
- **Claude Code** (`/code...`): directly below the **More** row (a button/link with text "More"), above "Recents".
- Rows are located by climbing from the matching element to the highest ancestor whose text is still just that label.
- **Fallback**: if no anchor is found, or the anchor is hidden / narrower than 120 px (collapsed sidebar), the old floating
  pill/panel (below) is used. A `MutationObserver` (throttled to ~4 checks/s), `popstate`/Navigation events and a 2 s heartbeat
  re-run the placement, so route changes and re-renders move the host back; only one host (`data-claude-usage-host`) ever exists.
- Looks native: the host inherits `font`/`color` from the sidebar, the card is a low-contrast fill (`currentColor` at 6 %) with a
  hairline border, 12.5 px text, muted text at 65 % opacity, 4 px bars (green < 60, amber < 85, red >= 85). Light/dark comes from the
  luminance of the sidebar text colour (`data-theme` on the host), not from `prefers-color-scheme`. Left/right inset = inset of the
  row's inner link inside its wrapper.
- Contents: header "Usage" (chevron collapses; state in `widgetUi.panelCollapsed`; the collapsed header shows "42% · 2:14:02") and a
  settings gear; plan bars (five_hour and seven_day full size; other windows such as Opus/Sonnet compact) with a **live**
  "resets in 2:14:05" (`h:mm:ss` under 24 h, `3d 4h 12m` beyond; one 1 s interval that only rewrites `.cd` text nodes, running only
  while the panel is attached and the tab is visible); segmented control Session (5h) · Today · 7 days; per-model share rows
  `sonnet-5-5  62%  12.4k tok` (+ small message count, bar = share, largest-remainder rounding to 100 %, sorted desc, scrolls only
  if more than 8 models).
- Device data: **chat** = this browser's local aggregates (shown with "≈"); **code** = combined `byModel` of the hub devices selected
  in options (`codeDeviceIds`; empty = auto: every hub device with source `claude-code` or `desktop`), exact. Hub not configured shows
  "Connect your Usage Hub in options to see Claude Code usage" + link (`open-options`).
- Data refresh every 30 s and on `state-changed`. Options lists hub devices through the `get-hub-devices` UiRequest.
- Preview: `dist/widget-preview.html?mode=chat|code|floating&theme=dark|light[&hub=off]` mounts into mock sidebars.

### Floating fallback
A closed-Shadow-DOM widget (`src/widget/widget.ts`), fixed bottom-right (right 16 px, bottom 88 px by
default; drag vertically to move, position remembered). Constructable stylesheet, system font, follows
`prefers-color-scheme`. Disable via "Show widget on claude.ai" in options (`showWidget`, applied live).
- **Collapsed pill** (44 px): mini ring + "5h 42%" (or "Usage" if unknown). Click to expand.
- **Panel** (340 px wide, max 70 vh, scrolls): header "Claude usage" + sync dot + settings gear + minimize (Esc also collapses).
  - Plan usage bars per account window (five_hour "Current session (5h)", seven_day "Weekly · all models",
    seven_day_opus/sonnet, others title-cased) with % and "resets in 2h 14m"; green <60, amber <85, red >=85.
    Empty: "Plan usage unavailable".
  - Tabs: Session (5h) · Today · 7 days (ARIA tablist, arrow keys).
  - Device cards: "This browser" (local aggregates, always available) then hub devices (own deviceId excluded)
    with source badge (Claude.ai / Claude Code / Desktop), "stale · seen 2h ago" when not fresh, a totals line
    ("≈" only for estimated sources) and per-model rows (name without "claude-", messages, tokens, bar). Collapsible.
  - Footer: "Updated 12s ago" and hub status; when no hub is configured: "Connect a Usage Hub to see Claude Code & Desktop" (opens options).
- Refresh: on expand, every 30 s while open, every 60 s collapsed, and immediately on the service worker's `state-changed` broadcast.
- Fails soft: errors are logged as `[claude-usage]` warnings; claude.ai requests are never touched.
- Manual visual check: `npm run build`, then open `dist/widget-preview.html` (stubbed chrome.* with fake state).

The popup below is kept as a secondary UI.

## Popup (≈320 px wide)
- Header: device name + sync dot (green = synced < 2 min ago, amber, red + error tooltip)
- Tabs: **Today · 5h · 7d**
- Big numbers: messages, ≈ tokens (prompt / output)
- Per-model list: model name, messages, ≈ tokens, small bar
- Account usage row (if available): "5-hour limit 42% · resets 17:30"
- Footer: "Token counts are estimates" link to options

## Options page
- Device name
- Hub URL + "Test connection" button (calls `GET /api/ping`; https, or http for local testing with a warning)
- Hub token
- Chars-per-token slider (2.5–5, default 3.6)
- Toggle: poll account usage
- Buttons: Export JSON · Clear data
