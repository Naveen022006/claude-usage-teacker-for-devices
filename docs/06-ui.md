# 06 — UI

## Popup (≈320 px wide)
- Header: device name + sync dot (green = synced < 2 min ago, amber, red + error tooltip)
- Tabs: **Today · 5h · 7d**
- Big numbers: messages, ≈ tokens (prompt / output)
- Per-model list: model name, messages, ≈ tokens, small bar
- Account usage row (if available): "5-hour limit 42% · resets 17:30"
- Footer: "Token counts are estimates" link to options

## Options page
- Device name
- Hub URL + "Test connection" button (calls `GET /api/ping`; https, or http for local testing with a warning)
- Hub token
- Chars-per-token slider (2.5–5, default 3.6)
- Toggle: poll account usage
- Buttons: Export JSON · Clear data
